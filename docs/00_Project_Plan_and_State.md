"# Project Charter and Semantic Model Status\n\n**Document Version:** 1.0 (Initial Build)\n**Last Updated By:** AI Assistant / User Collaboration\n**Purpose:** To serve as the single source of truth for the data model's scope, architecture, business definitions, and current state, ensuring context continuity across all future interactions.\n\n--- \n\n## 🎯 1. Project Goal & Objective\n\nThe primary goal is to analyze the relationship between various lifestyle factors (sleep, activity, screen time) and mental health outcomes (stress, anxiety, depression) among teenagers.\n\n**Business Question:** What behavioral patterns are strongly correlated with a higher Total Distress Score? \n\n## 💾 2. Data Scope & Source Information\n\n*   **Source Dataset:** `Teen_Mental_Health_Dataset.csv` (Kaggle download).\n*   **Scope:** The dataset covers demographic, behavioral, and measured mental health indicators.\n*   **Limitation:** This model is based on a snapshot of data and should not be used for longitudinal studies without external validation or time-series grouping fields.\n\n## 🏛️ 3. Current Semantic Model Architecture (The 'How')\n\nThe model uses a single fact table (`Teen_Mental_Health_Dataset`) with no current relationships, which is standard practice for initial data loading and measurement creation.\n\n### A. Key Components:\n1.  **Fact Table:** `Teen_Mental_Health_Dataset` (Contains all raw metrics).\n2.  **Calculations/Measures Layer:** Defined in `_calculations.tmdl`. This layer abstracts complex calculations from the user, ensuring consistency.\n\n### B. Key Business Metrics:\n*   **Total Distress Score (TDS):** The composite score of overall psychological burden. **(Higher = Worse)**\n    *   *Calculation:* Sum of `stress_level` + `anxiety_level` + `depression_label`.\n*   **Sleep Efficiency Index (SEI):** Measures sleep quality relative to tech usage. **(Higher = Better)**\n    *   *Calculation:* `sleep_hours / (1 + screen_time_before_sleep)`.\n*   **Lifestyle Balance Score (LBS):** Combines physical health and rest habits. **(Higher = Healthier)**\n    *   *Calculation:* Sum of `physical_activity` + `sleep_hours`.\n\n## ⚠️ 4. Core Assumptions & Model Limitations\n*(These must be revisited before any major analysis)*\n\n1.  **Score Interpretation:** All level/score columns (TDS, etc.) are assumed to have a monotonic relationship where **higher values indicate increased risk or severity.**\n2.  **Units:** Time-based metrics (`hours`) are assumed to be consistently measured in **Hours**.\n3.  **Weighting:** The model assumes that the contributing factors (e.g., stress, anxiety, depression) contribute equally and linearly to the Total Distress Score (TDS).\n4.  **Causation vs. Correlation:** All derived insights must remember that correlation does not equal causation. \n\n## 🗺️ 5. Future Development Roadmap (Next Steps)\n\n1.  **Validation:** The top priority is having a Subject Matter Expert validate all core assumptions, especially the interpretation of score scales.\n2.  **Advanced Analytics:** Develop measures that calculate **ratios and interactions** (e.g., `TDS` by `platform_usage`, or predicting LBS based on high screen time).\n3.  **Reporting Focus:** Build interactive dashboards centered around comparing behavioral inputs (X-axis: Screen Time, Physical Activity) against the key derived metrics (Y-axis: TDS, SEI).
